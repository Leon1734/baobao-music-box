# 照片目录

把**宝宝的照片**放进这个目录，播放器首页会自动轮播。

## 用法

1. 放图片进来（支持 `jpg` / `jpeg` / `png` / `webp` / `gif`）
2. 刷新播放器页面 —— 首页右侧就会开始轮播
3. 按文件名排序播放，想控制顺序就用 `01_xxx.jpg`、`02_xxx.jpg` 这样命名

## 为什么仓库里没有照片

这是你的**私人照片**，不应该出现在公开仓库里。所以：

- 本目录内容已被 `.gitignore` 排除
- 打包 exe 时也不会打进去
- 你把自己的照片放进去了，exe 转发给别人时**别人看不到你的照片**（他们看到的空目录或自己的照片）

## 性能建议

直接放大图（手机拍的原图单张 3-20MB）也能用，但首屏会慢。
可以跑一下压缩脚本，把图片压到约 200KB：

```bash
python tools/make_photos_web.py
```

这会在同级生成 `photos_web/` 压缩版目录，程序会**优先用压缩版**，
原图仍保留作为回退（不会改动你的原图）。

压缩版同样不会被提交到仓库。
