# 音源目录

把你自己收集的 **洛雪 / LX Music 音源 `.js` 文件** 放到这个目录，程序会自动识别并显示在「设置 → 音源管理」里。

## 为什么仓库里没有音源文件

1. 这些文件**不是本项目的代码**，是第三方作者分发的
2. 它们内部通常**带第三方 API 密钥**，不适合随公开仓库分发
3. 各家音源随时会更新/失效，跟着仓库走很快就过期了

## 怎么加

1. 从你获取音源的渠道下载 `.js` 文件
2. 直接丢进这个目录（子目录不扫描）
3. 打开播放器 → **设置 → 音源管理**，确认列表里出现了

> 文件名随意，建议保留版本号，方便区分，例如 `某某音源 v1.2.0.js`。

## 说明

- 程序**不会**执行这些 JS（浏览器环境下跑不起来 LX 的运行时）
- 它们的作用是：被**服务端解析**出音源接口配置，用于在线取播放链接
- 在线搜索、榜单、推荐走的是公开接口，**不依赖**这个目录
